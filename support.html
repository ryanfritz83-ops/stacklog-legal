StackLog Support

App Store name: StackLog Daily

StackLog is a local-only daily supplement tracker. There is no account to create and no cloud sync.

Common questions

Where is my data? On this device only (unless you export a backup).

Reminders not firing? Enable Daily reminders in Settings and allow notifications for StackLog.

Widget? Add the StackLog widget from the iOS home-screen widget gallery after installing from the App Store or TestFlight.

Lost data after reinstall? Restore from a backup JSON you previously exported in Settings, if you have one.
